ABOUT

Study hard.
Game harder.
Show both.

Grind Tracker is a study + gaming tracker that lives on your own PC. It turns your focus time, Steam play time and progress into a live card on your Discord profile, plus a dashboard that's actually fun to keep open.

Open the dashboard View on GitHub ↗

01Why it exists

Your Discord profile shows what you play, but never what you study. Grind Tracker puts both side by side, so your friends see the grind and you have a reason to keep the streak alive.

Discord's profile "Widgets" board is only open to officially claimed games. So Grind Tracker uses Rich Presence, the "Playing …" card that any app on your PC can set.

02Your data stays yours

  • Everything runs on localhost. There's no account, no cloud and no tracking.
  • Study history lives in data.json, and your keys live in .env, both in the app folder.
  • The app only talks to the Steam Web API and to your own Discord desktop app.
  • The local server refuses requests from any other website.

03What's inside

  • Node.js server with no framework: one file serves the dashboard and the API.
  • Steam Web API for your profile, play time, achievements and global rarity.
  • Discord RPC via @xhayper/discord-rpc for the profile card.
  • Plain HTML, CSS and JS dashboard: canvas aurora, segmented bars, no build step.
