        SETUP

        Connect your accounts

        Everything stays on this computer. Your keys are saved in a .env file in your Grind Tracker data folder, and only ever go to Steam and your own Discord app.

        01
        Discord Application ID
        1. Open the Discord Developer Portal ↗ and click New Application.
        2. Its name is what your profile shows after "Playing", so make it cool.
        3. On General Information, copy the Application ID.
        02
        Steam Web API key
        1. Go to steamcommunity.com/dev/apikey ↗ and sign in.
        2. For the domain name, type localhost, then copy the key.
        03
        Your Steam profile
        1. Paste your profile link (open my profile ↗) or your SteamID64 from steamid.io ↗.
        2. Set Game details to Public in privacy settings ↗ so play time shows up.
        Optional: Discord card image

        Upload public/img/logo-small.png under Rich Presence → Art Assets in the Developer Portal with the name logo, then type logo here. A direct https:// image link works too.
